登录界面

Console Experience Desktop Manager 是一款以手柄为先的登录界面，适用于 LineXinBar 和普通的 Linux 桌面会话。

它绘制 LineXinBar 自己的壁纸、配色和玻璃，可以用手柄、键盘或指针操作，而且没有哪一种是单独的模式。它可以启动机器上的任何 Wayland 会话 — LineXinBar、Plasma 或其他 — 并交给 LineXinBar 一份记录，让壁纸在同一时刻继续流动，所以登录看起来是一幅连续的画面，而不是两个程序轮流登场。它支持 Shell 的十种语言，并遵循您的强调色和粒子设置。

它还没有准备好成为一台机器唯一的显示管理器 — 请在空闲的 VT 中试用，或使用它的预览模式，预览模式从不启动会话。

Software Hub

DistriBumpy 显示为 Software Hub，是一个用手柄操作的 Flatpak 商店。

  • 它打开时是一个首页，展示 Flathub 自己认为值得一看的内容 — 最受欢迎、上升最快、新近发布和刚刚重新构建的应用 — 即使没有网络也能打开。
  • 货架与 Shell 的列一一对应，这样您找到的东西会出现在您会去找它的地方。
  • 在您按下之前，就说明一次安装的真实开销 — 下载量和磁盘占用，包括它会带进来的每个运行时。
  • 安装、更新和删除时显示可以随时停止的进度，并清理不再被任何东西需要的运行时。
GitHub 上的 DistriBumpy

音乐

SongOnSole 显示为音乐，是主栏的音乐货架打开的音乐库和播放器。

底部那一行在每一页上既显示正在播放的内容，也是播放它的方式。一首歌从按下它的那一行中展开，它的封套放大成“正在播放”页面。六种排序方式，一个按您排列的顺序播放的队列，而且在掌机的小屏幕上和电视上一样好用。

GitHub 上的 SongOnSole

视频

Videonsole 显示为视频，是专为手柄打造的影片浏览器和播放器。

影片从按下它的那张卡片中展开，结束后再回到卡片里。播放中的影片占据整个屏幕；按任意键，控件就会浮现，四秒后再沉下去。它会记住看到了哪里，能找到影片内部或旁边的字幕，并在机器支持时使用显卡解码。

GitHub 上的 Videonsole

图片

Imagonsole 显示为图片，是一款用手柄操作的照片查看器。

照片从它的卡片中以完整分辨率打开，左右两侧的图片已预先读取，所以翻看一个文件夹永远不用等待。A 会逐级放大；扳机键或滚轮可以平滑缩放。当图片比屏幕大时，方向键用于平移；不比屏幕大时，则切换到下一张。

GitHub 上的 Imagonsole

lxb-toolkit

Shell 自己的界面 — 它的颜色、玻璃、动效、字体、标记和声音 — 打包成一个库，让应用程序可以用同样的材质构建，与 Shell 并肩而立。

上面四款应用都基于它构建。lxb-new my-player 会为您生成一个可以直接构建的 Wayland 应用程序，可选 Rust、C 或 Python：用一个函数描述页面上有什么，由键盘、指针和机器上的每个手柄操控，而且没有一行代码写明颜色、圆角或时长。工具包应用程序是普通的 Wayland 程序，所以在 GNOME 或 Plasma 下运行得和在 LineXinBar 下一样好。

lxb_app::App::new("com.example.hello", "Hello World").run(|page| {
    page.head("launch", "Hello, world");
    if page.button("Hello World!") {
        println!("clicked");
    }
})
GitHub 上的 lxb-toolkit

同一个版本号

LineXinBar 与它的六个兄弟项目一起发布，共用一个版本号 — 今天是 0.9.3 — 这样看一个号码就知道装的是什么，而不是七个各自漂移的号码。

在没有发行版仓库收录的情况下，设置 › 更新会从它们各自在 GitHub 上的发布版本把七个项目全部更新到最新。
