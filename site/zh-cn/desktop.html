LineXinBar 的桌面必备：截图、共享、对话框

  1. 截图指南键和右肩键
  2. 屏幕共享在通话或直播中共享显示器
  3. 选择文件可以用手柄操作的打开和保存对话框
  4. 密码请求当系统询问您是谁时
  5. 保持唤醒影片或游戏会让屏幕保持点亮
  6. 与您的应用协同工作Wayland、X11 和 Flatpak

截图

同时按住指南按键和右肩键 — 与 Steam Deck 拍照的组合键相同 — 或者按键盘上的 Print。

屏幕闪一下白光，响起快门声，您正在操作的那块显示器的画面就会存入图片中的 Screenshots 文件夹，片刻之后出现在图片货架上。无论同时按着什么，Print 都有效，所以习惯了其他桌面各种变体的手也能一次按对；没有 Print 键的键盘可以使用 Ctrl+Shift+3。

屏幕共享

OBS 录制会话、Discord 共享会话，方式与任何其他 Linux 桌面相同 — 通过屏幕共享门户。

当应用程序请求时，Shell 会在自己的面板上询问您要共享哪台显示器。没有这个回答，任何程序都无法录制屏幕：程序不能背着您抓取画面。

选择文件

要上传照片的浏览器、要找地方保存的编辑器、要为模组选文件夹的游戏 — 它们得到的都是 Shell 自己的选择器。

其他桌面的文件对话框是一棵树、一个列表和一个文本框，没有一个能用手柄操作。在这里，问题会在您已经熟悉的文件列中、在一块大玻璃面板上得到回答；保存时会停在保存到此处，文件名已经写在下面。在浏览器中点在文件夹中显示，也会把主栏带到文件中的那个文件夹，而不是在 Shell 上方另开一个文件管理器。

密码请求

挂载磁盘、安装更新、更改系统设置 — 当系统需要管理员同意时，Shell 会在自己的面板上询问，并伴有提示音让您注意到。

密码由系统本身验证，从不经过 Shell，一旦交出就会从内存中清除。没有这样的代理，桌面会直接拒绝这些请求，屏幕上也没有任何允许它们的办法。

保持唤醒

正在播放的影片或正在运行的游戏会让屏幕保持点亮、机器保持唤醒，正如您所期望的 — 包括 Flatpak 中的游戏，比如 Heroic 或 RPCS3 从 Flathub 启动的一切。

当没有东西阻止时，屏幕会按照您在电源中设置的等待时间变暗、熄灭并进入睡眠。

与您的应用协同工作

普通的 Linux 应用程序在这里照常运行：原生 Wayland 程序、通过 Xwayland 运行的 X11 程序，以及 Flatpak。

启动的应用程序会占满它所在的屏幕 — 这就是主机模式 — 而指南是在它们之间切换的方式。通过 Proton 原生运行在 Wayland 上的游戏能得到它们需要的一切：显式同步、为最低延迟而允许的画面撕裂，以及直达显示器的 HDR。
