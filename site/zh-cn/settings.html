强调色

强调色是一整套配色，而不是单一颜色。选择一种会改变所选行上的光、玻璃、光晕 — 壁纸也随之改变，因为它的丝带、光幕和闪光都是用强调色绘制的。

无需重新加载：一切都会同时过渡到新的配色，所有显示器一起变化。试试吧 — 这个页面用的就是同样的十二种配色，您选择的那一种会在本站的每一页上伴随您。

在 Shell 中，它位于设置 › 外观 › 强调色，保存为一行您也可以手动编辑的内容：~/.config/lxb/shell.toml 中的 accent = "Blue"。

主题

Shell 由什么构成 — 图形本身永远不变，变的只是材质。三行设置，彼此独立，因为每一项都有自己的开销，也各有各的喜好。

  • 壁纸。默认是一条三层厚的水带，像实体一样被照亮。简约是 Shell 以前绘制的三条纤细的玻璃丝带，绘制开销约为一半。
  • 图标。默认把每个标记立成一颗水珠，按其自身形状着色。简约则绘制它的平面形状。
  • 粒子。水流洒出的闪光 — 它们出现在丝带中间，被推出丝带，越远越淡，就像 PlayStation 3 的波浪带着它们一样。

登录界面、会话启动画面和兄弟应用都会遵循同样的选择。

您自己的壁纸

“壁纸”下的第三个选项是您自己的图片或影片，放在 Shell 场景原本所在的位置。

它在 Shell 自己的文件浏览器中选择，浏览器只列出可以放在屏幕背后的内容 — 图片和影片 — 每一项都会在自己的行上显示预览。它会被裁剪以填满屏幕而不是被拉伸，在指南后面会被调暗，并由 Shell 保存一份，所以移动或删除原文件也不会让您失去壁纸。

语言

十种语言：Deutsch、English (UK)、English (US)、Español、Français、Polski、Português (Brasil)、Русский、हिन्दी 和 简体中文。

在这里的选择是整台机器的语言，而不是 Shell 的私有设置：Shell 会立即在每台显示器上换成新语言，然后让系统也说同一种语言 — 这样您接下来打开的应用程序也会与它一致。可能需要重启，才能让一切都跟着切换。登录界面也支持同样的十种语言。

语言和翻译

网络和蓝牙

从空中可用的网络列表中（信号最强的在前）选择并连接 Wi-Fi，然后在屏幕键盘上输入密码。

有线连接有自己的页面，可设置自动或手动的地址和名称服务器，连接信息无需终端就能回答“我的 IP 地址是多少”。连接期间，主屏幕的角落会显示无线标记。

蓝牙用同样的列表配对耳机、手柄和键盘，在设备需要时询问 PIN 码，并记住会话开始时蓝牙是否应当开启。

声音

选择整台机器通过什么播放和录音 — 所有应用程序，而不只是 Shell。

接着是 Shell 自己的声音：每次移动和每次按下都有音效，指南有不同的声音，让您听得出正在操作哪块屏幕，收到通知时有提示音，没有打开任何程序时主屏幕上还会播放音乐。本站使用同样的音效，也播放同样的音乐 — 可以在它的指南中关闭其中任何一个，或调节音量。

电源

主机被放下时会做什么：稍后屏幕变暗，然后熄灭，放置得足够久，机器就会进入睡眠。

再拿起来 — 任意按键、鼠标、手指或手柄上的按键 — 它仍停在原来的位置。您可以选择四段等待时间、电源按钮的作用，以及在有此功能的机器上的电源模式和省电模式。这些属于设备而不是账户，所以登录界面也会遵循。

用户和存储

用户可以添加账户、设置谁是管理员、更改密码和头像，以及删除账户 — 系统会在必要时要求输入密码。

存储会列出每个驱动器上的每个分区及其占用情况，并让您选择哪些分区在每次开机时挂载。系统信息会用通俗的话告诉您这台机器是什么。

更新

按下全部更新，看着一条进度条。对大多数人来说，就这么简单。

每一行下面都写着按下会发生什么 — 4 个更新、已是最新、无法检查 — 面板会说明有多少个更新，以及之后是否可能需要重启。立即更新是唯一的问题；系统、Flatpak、固件和 AUR 只需输入一次密码即可全部更新，进度条会逐一计数，需要时最后还会出现立即重新启动。

在没有软件仓库收录的情况下，Shell 及其兄弟项目也会从各自在 GitHub 上的发布版本自行更新。

低配硬件模式

适用于 Shell 负担太重的掌机或旧机器。开启后，Shell 会以最省资源的方式绘制自己，而它的工作方式不会有任何变化。

  • 壁纸静止不动，只绘制一次，而不是每帧的每个像素都重新绘制。
  • 使用简约材质，也没有闪光，无论主题页面怎么设置。
  • 有东西在动时，主栏仍以显示器自身的刷新率平滑滑动；没有东西在动时，则降到每秒十帧。

在编写它的那台机器上，主屏幕的图形耗时从每秒 44 毫秒降到了 2 毫秒。需要它的机器上不必有人去找这个开关：在没有图形芯片的地方，它会自动开启，并加以说明。

看不见的东西根本不会被绘制，无论是否开启此模式 — 被遮挡的 Shell 和被遮挡的应用程序都会降到零，因此前台的游戏能获得整个 GPU。
