Bildschirmfotos

Halten Sie die Guide-Taste und die rechte Schultertaste zusammen — dieselbe Kombination, mit der ein Steam Deck ein Bild macht —, oder drücken Sie Print auf der Tastatur.

Der Bildschirm blitzt weiß auf, der Verschluss klickt, und das Bild des Bildschirms, den Sie steuern, landet im Ordner „Screenshots“ in Ihren Bildern, wo es einen Moment später im Bilder-Regal steht. Print funktioniert, egal was Sie dazu halten, sodass eine Hand, die an eine Variante eines anderen Desktops gewöhnt ist, es richtig macht; eine Tastatur ohne Print-Taste kann Ctrl+Shift+3 benutzen.

Bildschirmfreigabe

OBS nimmt die Sitzung auf und Discord teilt sie, genauso wie auf jedem anderen Linux-Desktop — über das Portal zur Bildschirmfreigabe.

Wenn eine Anwendung fragt, fragt die Shell Sie, welchen Bildschirm Sie teilen wollen, in ihrem eigenen Feld. Ohne diese Antwort kann nichts den Bildschirm aufnehmen: Programme können ihn nicht hinter Ihrem Rücken abgreifen.

Eine Datei auswählen

Ein Browser, der ein Foto zum Hochladen will, ein Editor, der einen Speicherort will, ein Spiel, das einen Ordner für seine Mods will — sie alle bekommen die eigene Auswahl der Shell.

Die Dateidialoge anderer Desktops sind ein Baum, eine Liste und ein Textfeld, und keines davon ist mit dem Controller erreichbar. Hier wird die Frage in der Dateien-Spalte beantwortet, die Sie schon kennen, auf einer großen Glasfläche; ein Speichern öffnet sich auf Hier speichern, mit dem Namen schon darunter. Im Ordner anzeigen in einem Browser führt die Leiste ebenfalls in diesen Ordner in den Dateien, statt einen anderen Dateimanager über der Shell zu starten.

Passwortabfragen

Ein Laufwerk einhängen, eine Aktualisierung installieren, eine Systemeinstellung ändern — wenn das System die Zustimmung eines Administrators braucht, fragt die Shell, in ihrem eigenen Feld, mit einem Klang, damit Sie es bemerken.

Das Passwort prüft das System selbst, nie die Shell, und es wird aus dem Speicher gelöscht, sobald es übergeben ist. Ohne einen solchen Agenten lehnt ein Desktop diese Anfragen einfach ab, ohne dass etwas auf dem Bildschirm erscheint, um sie zu erlauben.

Wach bleiben

Ein laufender Film oder ein laufendes Spiel hält den Bildschirm hell und das Gerät wach, wie man es erwartet — auch Spiele aus einem Flatpak, wie alles, was Heroic oder RPCS3 von Flathub startet.

Hält nichts ihn an, wird der Bildschirm dunkler, dann dunkel und schläft nach den Wartezeiten ein, die Sie unter Energie einstellen.

Funktioniert mit Ihren Apps

Gewöhnliche Linux-Anwendungen laufen hier, wie sie sind: native Wayland-Programme, X11-Programme über Xwayland und Flatpaks.

Eine gestartete Anwendung füllt ihren Bildschirm — das Konsolenmodell —, und der Guide ist der Weg, zwischen ihnen zu wechseln. Spiele, die über Proton nativ unter Wayland laufen, bekommen, was sie verlangen: explizite Synchronisation, Tearing für die geringste Latenz und HDR bis zum Bildschirm durchgereicht.
