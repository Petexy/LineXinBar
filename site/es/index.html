LineXinBar — un escritorio de consola para Linux al estilo XMB, para sus juegos, aplicaciones y contenido multimedia

Use las flechas, un mando, la rueda del ratón o un deslizamiento para moverse por la barra, y Intro, el botón frontal inferior o un clic para abrir lo que está iluminado.
